# v12 모델·적용 범위

- 기호: CPU OpenCV DNN의 YOLOX-Nano 단일 클래스 후보, ONNX SHA256 `56ac65841a91cb60d816995335ba3def4f923d7ab25d7687b38d2bb64453a3ff`. 밸브·펌프·계기의 의미나 표준 식별자를 학습·인증하는 모델은 아니다.
- 학습: v11의 v6/v9 평균 가중치를 시작점으로 BN 통계를 고정한4epoch·32steps/epoch·batch4·AdamW lr2e-5. 이전 replay와 이제 학습으로 전환한 White Rose45개 기호의 누락/경계 오차 중심 크롭. 데이터·초기 가중치 해시·seed는 TRAINING-DATA.json, TRAINING-FROZEN-BN.json에 기록했다. 같은 프로젝트는 새 프로젝트 평가에서 제외했다.
- 추론: threshold0.6, 원본 최대4800px·겹치는1024px 타일·640px 네트워크 입력. 최대4개384px 선택 크롭, 총37뷰 이내. base 후보를 보존하는 추가 전용 NMS, 기하 후보와 낮은 점수의 작은 검출이 위치를 제안한다. 신경망이 실제로 검출해야 후보가 된다.
- OCR/연결: 최대2400px에서 기존 Tesseract와 검증된 선·포트·접점 추적기를 사용한다. 병렬 OCR은 실행 순서만 바꾸며 PNG 전체 OCR을 자동 마스킹하지 않는다. 혼합 PDF는 원본 래스터 배치를 OCR 영역으로 사용한다. OCR 정답 기반 정확도 평가는 아직 없다.
- 공동 모델:42KB 공유 지역 CNN, 포트2·접점4·선종3의 세 head. SHA256 `4e6accd5b95db0169620b9f627fa0003b095aa53dfa6972cbb031b0356b5ab68`. 실제 AI 주석/합성7,181패치로 학습했다. 개발 OPEN100에서 선정 추적기보다 낮아 기본 꺼짐. 설정 `topology_context`의 `joint_context`/`joint_mix`로 실험할 수 있고 validate_pipeline.py가 비교한다. 전역 그래프를 공동 최적화하는 모델은 아니다.
- 평가 역할: 기존20페이지·기존 확대 주석은 후보 선정용 개발 데이터. Peterhead/EPA의4개 새 프로젝트 영역45기호·53연결은 코드와 source-only AI 주석 동결 후 평가했다. 단일 AI 주석, 작은 범위, IoU0.5/무방향 인접 관계의 한계가 있다. 현업 독립 정답·다양한 산업·건축/기판 도메인에 대한 추가 평가가 필요하다.
- 제안 계층: 범례 검색은 같은 프로젝트 원본 템플릿에만 의존하고 자동 적용하지 않는다. LLM은 오프라인 구조·근거 검증·dry-run 평가만 지원한다. 제공자 호출이나 실제 LLM 성능 측정은 없다.
- 모든 점수는 보정된 확률이 아니며 후보의 `needs_review`를 유지한다. 최초 예측, 원본 관찰과 사용자의 교정은 분리 저장한다. 인명·설비의 안전 판단, 물리적 연결/유량 확정 또는 변경 자동 승인에 사용할 수준을 보장하지 않는다.

실패한 후보·프로젝트별 회귀와 실제 수치는 [평가 보고서](REPORT.ko.md), 운영 검증은 [배포 기록](DEPLOYED.json)을 참조한다.
