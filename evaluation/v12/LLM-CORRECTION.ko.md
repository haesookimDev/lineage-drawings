# LLM/VLM 보정 제안과 평가 준비

사용자 선택에 따라 **제안 구조·검토·평가만 구현**했습니다. 제공자 SDK·API 키·모델 호출·외부 도면 전송은 없습니다. `author_model`은 가져온 파일의 자체 기록이며 실제 LLM 실행 증거가 아닙니다. 테스트 fixture 결과를 LLM 정확도 향상으로 주장하지 않습니다.

## 준비된 처리 순서

1. `GET /api/pages/{id}/correction-pack`: 보호된 원본 이미지 참조·크기·해시, 검출 요소, 관찰 연결 경로, 사내 의미 사전, 근거 ID, 검토 상태의 스냅샷 해시를 제공합니다. 최대 120요소·100의미 제한과 잘림 여부를 표시합니다. 원본 텍스트·OCR는 명령이 아닌 비신뢰 데이터로 취급하도록 지시문을 포함합니다.
2. `GET /api/correction-schema`: 엄격한 JSON 스키마와 평가 지표를 내보냅니다. `rename`, `add_symbol`, `set_kind`, `connect`만 허용합니다. 각 제안에 근거 ID·사유·자체 신뢰도가 필요합니다. 임의 표준 ID 필드는 거절합니다. 의미 연결은 실제 사전 ID와 그 근거가 있어야 합니다.
3. `POST /api/pages/{id}/llm-proposals`: `schema: lineage-correction-proposals-1`, `snapshot_sha256`, `author_model`, `proposals`를 검증합니다. 알 수 없는 필드·위조 근거·다른 페이지 ID·만료된 원본·빈 이미지 영역·관찰 경로 없는 연결은 거절합니다. 연결 제안은 이미 관찰된 경로와 양 끝점이 일치해야 하므로 새로운 미관찰 배선을 상상해 추가할 수 없습니다. 추가한 기호를 같은 배치에서 새 배선에 연결하는 기능은 아직 없습니다.
4. `GET /api/pages/{id}/assistance`: 원본과 분리된 제안·실행 기록을 조회합니다.
5. `POST /api/proposals/{id}/review`: 담당자가 버전과 적용/제외를 지정합니다. 대상이 바뀌면 충돌을 반환하며 적용해도 `needs_review` 상태입니다. 최초 분석 스냅샷·원본 포트·경로는 유지하고 적용 전 대상과 제안을 이력에 저장합니다.
6. `POST /api/pages/{id}/proposal-evaluation`: 같은 프로젝트·동일 원본·동일 페이지의 확정 정답 `annotation_id`와 `run_id`를 받아 최초 예측 대비 제안을 가상 적용해 평가합니다. 화면·DB 요소에는 적용하지 않습니다. 이미 수동 수정된 상태에서 만든 실행은 비교 기준 오염을 막기 위해 거절합니다.

## 이후 실제 LLM 평가 방법

동일한 학습 제외 도면을 프로젝트 단위로 나누고 정답을 먼저 확정합니다. `CV only`, `CV+legend`, `CV+LLM proposal`, `CV+human-reviewed proposal`을 구분해 기호·연결 P/R/F1, 문자 정답 오류율, 근거 없는 제안 비율, 담당자 수락률·검토 시간, 호출 지연·토큰·실제 비용을 측정해야 합니다. 신뢰도는 모델 자체 점수이며 검증셋으로 보정하기 전 확률로 제시하지 않습니다. 이번에는 실제 LLM 호출이 없으므로 지연·토큰·비용·LLM 성능 수치를 만들지 않았습니다.

가장 유용할 후보는 낮은 확신의 기호 이름, 중첩 OCR의 태그 복구, 범례와 사내 사전 후보 정렬입니다. 포트/교차·보이지 않는 배선은 이미지·관찰 경로 검증과 실무자 검토를 통과해야 합니다. 전체 페이지의 모든 요소를 한 번에 생성하기보다 작은 원본 크롭·주변 그래프·범례 근거를 묶은 제한된 제안으로 비교하는 구성을 권합니다. 현재 묶음은 전체 이미지 참조와 정규화 ROI를 제공하며, 외부 제공자용 크롭 전송 어댑터는 구현하지 않았습니다.

[From P&ID Drawings to Process Graphs: A Multimodal Language Model Approach](https://arxiv.org/abs/2607.19568)는 시각적 추출과 위상 추론을 나누는 참고 사례입니다. 두 ANSI 사례의 결과를 우리 도면의 성능 보장으로 사용하지 않았습니다. 현재 서버 검증은 좌표·근거의 존재와 버전 일관성 검증이며, 제안 의미의 진실성을 자동 인증하지 않습니다.
