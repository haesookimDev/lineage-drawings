# 타일 신경망 기호 검출기 v1

- 목적: 일반 기호 후보의 위치 검출. 출력 종류는unknown, 상태needs_review. 설비 종류·국제표준 번호·사내 의미·공학적 연결 승인을 자동 생성하지 않는다.
- 구조: 공식 YOLOX-Nano, depth0.33/width0.25/depthwise, 단일 일반 기호 클래스. COCO 초기 가중치에서 클래스 머리를 바꾸고 전체 층을 CPU로 미세조정했다. [공식 코드](https://github.com/Megvii-BaseDetection/YOLOX), upstream commit `6ddff4824372906469a7fae2dc3206c7aa4bbaee`.
- 데이터: 실제10장·부분 ROI(OPEN1000–3/Pāhala23·24/Virden5·7/Ruttan50·62), 합성12장. 원천 주석1,259개, 생성 타일607개. 제한된 일부 주석만 있는 실도면은 ROI 외부를 음성으로 쓰지 않았다. 타일607개는 독립 도면607장이 아니다. 운영 사용자의 도면은 학습하지 않았다.
- 학습: seed20261028, CPU4스레드, 배치4, 단계당96배치, 24단계, AdamW, 최대학습률0.0006, weight decay0.0001, warmup80배치, cosine 감소. 마지막4단계에 L1 추가. 실제 ROI 타일 상대 샘플링2.5, 나머지1.0, 복원 추출. 좌우 반전·대비/밝기·약한 Gaussian blur 사용.
- 학습 시간: 전체853.400초, 24×96×4=9,216개 타일 추출. 선택 모델은16단계이다. 8/16/24 체크포인트×문턱값0.15/0.3/0.45/0.6×후보 병합 방식3개를 별도7장으로 비교했다. 출처별 평균(connection F1 +0.25 localization F1) 최대값으로16/0.6/neural_only를 선택했다. 마지막24단계보다 검증 점수가 좋았다. [선정 기록](MODEL-SELECTION.json).
- 검증: OPEN1004·5/Pāhala20/합성4. 새 평가: Virden6·8/Pāhala22/Ruttan51의 사전 지정 영역, 기호32개·연결36개. 동일 프로젝트의 새 페이지이며 미지의 프로젝트 일반화가 아니다. v5에서 외부 테스트였던 Virden5·7/Ruttan50·62는 이번 학습에 편입했다. 역사적 회귀는 별도 집계한다.
- 입력: 최대4800px 원본에서1024px·20%중첩, 최대36타일+전체 페이지1개. 각640px BGR/0–255/우하단114 패딩. YOLOX raw x/y/logw/logh와 objectness×single-class score를 NumPy로 해석한다. NMS IoU0.4, 기호200개 상한. 점수는 보정된 확률이 아니다.
- 기존 경로:2400px 미리보기/OCR/선 추적과 DXF 파서는 유지한다. 신경망 후보를 사용하는 경로에서 사용하지 않는 HOG 추론은 생략하지만 연결 스타일 판정용 형상 분석은 남는다. PDF는 고해상도 렌더링을 추가하고 원본 문자 때문에 기호 예산이 사라지지 않도록 예산을 분리한다.
- 운영: ONNX를 OpenCV4.12 DNN CPU로 실행하며 PyTorch를 운영 이미지에 설치하지 않는다. CPU2/worker1/메모리1Gi. 실제 모델 SHA와 정량 평가는 FROZEN.json/REPORT.ko.md를 따른다. 학습과 내보내기 환경은training-environment.json에 있다.
- 검증 한계: 새 영역은 단일 시각 주석이고 독립 전문가 정답이 아니다. 기호 조립체 범위에 주석 불확실성이 있다. 작은 밸브·복합 장비·타일 경계·제목란·학습과 다른 도메인에 취약하다. 일부 페이지는 기존보다 낮은 재현율을 보였다. 기호 검출 개선이 연결 완전성을 보장하지 않으며 자동 영향 분석 확정 그래프로 사용할 수준은 아니다. 건축·전자회로 도면의 정확도를 검증하지 않았다.
- 권리·출처: [NOTICE](../../backend/assets/NOTICE.md). 공개 원본 PDF/페이지/타일/전체 OCR을 Git에 재배포하지 않는다. YOLOX 코드 Apache2.0 고지와 PID2Graph 유래 가중치 CC BY-SA4.0 출처를 보존한다. 정부 웹에 있는 제3자 문서의 별도 오픈 재배포 라이선스를 가정하지 않는다.

환경·데이터·학습·평가 실행 순서는 [재현 안내](REPRODUCE.ko.md)를 따른다.
