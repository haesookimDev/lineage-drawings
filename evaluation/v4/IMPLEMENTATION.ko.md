# v4 연결 누락·속도 개선 설계

기준 앱은 `2e111c42f33a02fb253b82a49e993c661e690ef3`이다. 최종 정확도·지연 시간은 [고정 비교 평가](results/report.json)와 별도 보고서에서 확인한다.

- 기존 OPEN100 8장의 연결 누락을 일대일 IoU 0.50 매칭으로 분해했다. 정답 1,393개 중 기존 복구 153개, 기호 누락 797개, 검출됐지만 연결 자격이 꺼진 기호 99개, 나머지 선·포트 추적 누락 344개다. 분류는 순서가 있는 진단이며 누락 원인의 독립적인 인과 비율을 뜻하지 않는다.
- 축선 모폴로지/Hough 최소 길이를 12px에서 7px로 줄여 작은 기호 사이의 짧은 관과 계기 접속선을 보존한다. 기호 경계와 선 중심의 2px 어긋남을 허용한다. 큰 간격이나 숨은 관을 임의로 잇지 않는다.
- 내부 문자 근거가 약한 원형 기호는 기존처럼 통과 선로를 끊지 않는다. 실제 선 끝이 닿을 때만 잎 접점으로 붙여 계기 누락을 줄인다. T자 접속, 점 있는 4방 접속과 점 없는 비접속 교차 정책은 지원 스타일에 한해 유지한다.
- 미지원 스타일의 기존 연결 후보는 보존한다. 더 짧은 선을 보는 두 번째 일반 선 추적으로 최대 100개 후보를 보충하며 총 500개 상한을 유지한다. 일반 경로는 여전히 교차를 확정하지 못하므로 모든 후보가 검토 대상이다. 추가 후보 때문에 FP가 늘어날 수도 있다.
- 73개 개발 전용 모델 자산과 원본 해시는 그대로다. 전체 해상도의 템플릿 검색 219회를 반해상도 후보 탐색과 원본 NCC 검증으로 바꿨다. 원본 검증 문턱은 0.78, 축소 탐색 문턱은 0.55다. 근사 탐색이므로 예측이 기존과 완전히 같다고 주장하지 않는다.

개발 중 원형 후보 간격 완화와 큰 폐곡선의 기호 추가는 오검출 및 경로 차단을 늘려 폐기했다. 초기 결과는 `iterations/short-lines-fast-search/`에 남겼다. 새 포트 그래프를 모든 일반 도면에 적용하는 시도도 합성 회귀에서 F1이 낮아져 채택하지 않았다. 일반 경로는 기존 후보를 보존하는 보충 방식만 사용한다.

평가기와 모델/코드는 새 실제 도면 평가 전에 [FROZEN.json](FROZEN.json)에 고정한다. 새 실제 도면은 OPEN100과 다른 설계사의 EPA 공개 Pāhala 하수처리장 P&ID 2장이다. 전체 페이지를 래스터로 입력하고 사전 지정한 공정 영역의 48개 기호·54개 연결만 채점한다. 원본의 전체 정답 데이터셋이 아니며 단일 시각 주석자에 의한 검증이다. 불분명한 SCADA/제어 버스와 23쪽의 플로트 조립체는 평가에서 제외했다. 상세 범위는 [계획](PLAN.json), [주석](pahala-labels.json)에 있다. 이 도면의 주석·형상을 모델 학습이나 파라미터 조정에 사용하지 않는다.
