# 모델 카드: 단일 YOLOX-Nano v10

용도는 PNG/JPG/PDF 미리보기의 일반 기호 위치 후보와 검토용 연결 추출이다. 기호 종류·국제표준 식별자·물리 흐름·설비 상태를 자동 승인하지 않는다.

- **가중치:** 기존 v6 epoch16과 v9 scale epoch8의 부동소수 상태를0.5로 선형 결합. BN통계 포함, 정수 버퍼는v9. 새 경사 학습 없음. 한 페이지에 신경망1개만 실행한다.
- **고정 파일:** `backend/assets/symbol-neural.onnx`, SHA-256 `64aa437392cc5d02134611bdae950dd1814e09d1f8c50b8baa79f1da59a300b5`. 원천 상태 해시와 OpenCV/Torch 허용오차는 `MODEL-CANDIDATES.json`.
- **입력/예산:** 최대4800px,1024px 타일·20% 겹침·전체 보기,640px 네트워크 입력. 최대36타일+전체1. 추가 확대0. 기호200·연결500 기존 상한.
- **선택:** 신경망 문턱0.6, neural_only, 로컬 형상 양식 확인. 이전20개 개발 페이지/ROI에서 OPEN100 회복 및 이전4영역 TP4/8/6/2보존을 제약으로 선정. 점수는 보정된 확률이 아니다.
- **추적:** 기존 이미지 증거 기반 점선/가지 복구와 포트0.45·접점0.35·추가 경로0.5·최대8경로점. RTrees 가중치는v8-R2와 동일. 새 접점/실선별문턱 실험은 최종 선택하지 않았다.
- **속도:** 전체 페이지 템플릿 제안 대신 후보 주변 양식 검색. RGB 적분 영상과 run/gap 배치 계산으로 반복 작업 축소. 실제10장의60회 paired 비교에서7.339→4.959초(32.4%단축), 확장4페이지만은8.706→6.543초(24.8%단축). 디코딩/렌더/네트워크/저장 제외, 운영 SLA아님.

원천 경사 학습은 v9의 실제20페이지/부분영역과 합성12장,1,332기호·769파생타일이다. Winkler/Winnipeg/운영 업로드의 새 경사 학습은 없다. 다만 이전35정답과 OPEN1006–11을 이번 개발에 쓰므로 독립 일반화 근거가 아니다. 확대78기호·102연결만 선택에서 제외했으며 전체 이미지/프로젝트는 이전에 노출됐다. 단일 AI주석으로 전문가 검증 정답이 아니다.

OPEN100 연결 F150.00→53.15%, R39.27→42.81%로 회복했지만 v8보다 정밀도는 낮고 일부 페이지는 악화된다. 이전35연결R57.14%는 그대로다. 확장 영역 전체는R34.31→33.33%, F137.04→35.98%로 하락했다. 큰 탱크·샘플/배수 표지·복합 조립체와 일부 가지/점선 누락이 남는다. 합성8장 F148.17→48.00%도 공개한다. [전체 결과](REPORT.ko.md).

코드: YOLOX Apache2.0, OpenCV 등 기존 라이선스 유지. PID2Graph/OPEN100 유래 가중치·기록의 CC BY-SA4.0 고지와 출처는 `backend/assets/NOTICE.md`에 유지했다. 정부 호스팅 도면의 재배포 권한을 가정하지 않으며 원본/PDF/페이지/오버레이/전체 OCR은 저장소·이미지에서 제외했다.
