# v9 작은 기호 검출·가지/점선 추적

공식 YOLOX-Nano 단일 일반 기호 모델을 CPU로 추가 미세조정했다. 의미 클래스나
ISA/ISO 식별자를 자동 확정하지 않는다. 실제20장(부분 ROI 포함)·합성12장,
원천1,332기호·769파생타일이며 기존 모델의 COCO/OPEN100 학습 이력을 계승한다.
이전 테스트10페이지73기호는 명시적으로 이번 학습에 옮겼다. Winkler·Winnipeg
세 시설 사업의 자료는 학습이나 문턱값 선택에 사용하지 않았다.

v6 선택 epoch16→first-pass12단계 중4→축소 증강8단계 중8을 선택했다.
좌우 반전·대비/밝기·약한 blur,80% 확률로0.35–1.0 축소 후 무작위 배치를 썼다.
정확한 seed·체크포인트 SHA·학습 이력은 TRAINING*.json에 있다. 재현 환경과
선택 과정은 README.md, SYMBOL/ROUTE-VALIDATION 파일을 따른다.

실행은 OpenCV DNN CPU·640입력, 최대4800원본·1024타일20%중첩·최대36+전체1개,
점수0.6·NMS0.4·기호200개 상한이다. 추가 확대는 검증상 선택하지 않아0개다.
선택된 후보 집합은 neural_only로, 기존 형상/HOG 후보와 자동 합치지 않는다.
포트·접점 RTrees 가중치는 v8-R2 그대로다. 포트0.45·접점0.35, 추가 경로 끝점0.5·
기호0.45·경로8점 상한은 검증으로 선택했다. 모든 점수는 보정된 공학적 확률이 아니다.

추적은 반복된 실제 잉크와 제한된 간격을 확인한 점선, 짧은 끝점3px 보정,
기호 경계 포트와 실제 팔/점 표시를 결합한다. 기호/OCR 내부 접점 제외와
점 없는 X의 비접속 관례를 유지한다. 전체 연결500, 선5000, 점 제안6000,
표시 접점500·선750의 상한을 둔다. DXF 원시 기하 연결은 유지한다.

새 평가는4개의 작은 영역35기호·35연결로 매우 작고 단일 AI 주석이다.
복잡한 조립체와 태그의 경계, 흐린 관로, 타일 경계, 작은 모터/배수 표지에
불확실성이 있다. 실제 엔지니어의 독립 검수와 추가 프로젝트 평가가 필요하다.
건축·PCB의 성능이나 전체 도면 정확도, 물리 흐름·변경 영향 분석의 신뢰성을
이 결과로 확정하지 않는다. 모든 후보는 needs_review이며 검토 저장과
포트/접점의 승인은 구분한다.

최초 비정상 실행은 검증과 다른 replace 병합 설정이었다. 배포 전에 발견해
선정된 neural_only를 복원했고, 가중치·문턱값·정답을 바꾸지 않고 재평가했다.
초기 결과를 최종 수치로 쓰지 않는다. VALIDATION-CONTRACT-FIX.json 참조.
원본 정부 PDF·이미지·전체 OCR과 운영 파일은 Git/컨테이너에 포함하지 않는다.
