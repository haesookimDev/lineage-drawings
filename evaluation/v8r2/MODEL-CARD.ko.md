# 포트·접점 문맥 모델 v8-R2

목적은 래스터 도면에서 검토할 포트·T/검은 점/비접속 교차 후보와 관찰 경로를 제공하는 것이다. 물리적 흐름, ISA/ISO 표준 식별자, 설비 안전성이나 변경 영향은 자동 확정하지 않는다.

두 OpenCV RTrees를 처음부터 CPU로 학습했다. 각160tree·depth18, seed20261030. 24/48px 주변 HOG·8×8잉크 격자·4방 선 지지·기하794차원이고 포트는 바깥 법선을 기준으로 회전한다. 입력에 페이지 ID·프로젝트명·정답 식별자를 쓰지 않는다. 포트10,123행(음성5,677/양성4,446), 접점3,504행(없음2,490/T568/점338/비접속108)이다. 정확한 데이터·특징·해시는 TRAINING.json을 따른다.

실제 수동 학습162점은 정부 문서8영역(71포트·31개 양성/음성 접점)과 OPEN1000–3에서 시각 검토한60개 점이다. 한 AI 주석자의 원본 시각 전사이며 전문가 독립 검수는 아직 없다. 약한 GraphML·생성 장면도 추가하며 각각의 한계를 별도 기록했다. 사용자가 업로드한 운영 파일은 학습하지 않았다. 이전 테스트6영역을 학습에 쓴 사실을 명시하며 일반화 결과에 포함하지 않는다.

기호 YOLOX-Nano는 v6 고정 가중치를 재사용한다. 토폴로지 CNN은 실행하지 않고 RTrees 점 주변 추론으로 대체했다. 원래 R2 포트 임계0.65·표시 접점0.45는 첫 새3장 평가 전에 고정했다. 이후 그래프 오연결 감사로 접속/표시 임계값과 실제 팔·OCR 제외를 통일하고, 새 연결의 끝점 점수0.75·기호0.8·경로4점 상한을 적용했다. 기존 연결500개 예산을 유지하며 이전 후보를 제거하지 않는다. 최종 그래프 개선은 사후 회귀이며 독립 블라인드 입증이 아니다.

점수는 보정되지 않은 트리 투표율이다. 공개 정부 문서3개 작은 영역에서는 포트11TP/2FP/13FN, 접점11TP/0FP/3FN이다. 큰 도면 전체 정확도·다른 회사 양식·스캔 품질·회전 도면으로 일반화할 수 없다. 특히 기호 누락, 희미한 선, 3px 이상의 점선 간격, 표/범례·텍스트 교차와 서로 붙은 조립체가 어렵다. 점 없는 X의 비접속 규칙도 도면별 관례 확인이 필요하다.

모든 후보는 needs_review다. 요소/연결을 승인해도 포트·접점 속성은 검토 필요 상태를 유지한다. 포트·접점 편집·확정 UI와 실제 엔지니어 검수가 후속 과제다. 원본 라이선스·학습 출처는 backend/assets/NOTICE-v8r2.md, 효과·실패·속도는 REPORT.ko.md, 정확한 배포 바이트는 FROZEN-RELEASE.json을 따른다.
