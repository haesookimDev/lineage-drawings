# Tiny U-Net 선·포트·접점 인식 모델 카드

- **용도:** 도면의 관찰 근거를 검토하는 보조 기능. 설비 흐름·표준 의미·안전 판단을 확정하지 않는다.
- **버전:** `backend/assets/topology.json`의 SHA-256으로 식별. epoch16, ONNX opset11,
  OpenCV DNN CPU. 3입력(회색조 잉크·적응 이진화·기호 박스), 6출력. 가중치 약232KiB.
- **출력:** 실선/점선, 포트, T, 4방 접속, plain crossing의 점수 지도.
  점수는 보정된 확률/정확도가 아니다. 별도의 기하학·가시 잉크 필터를 거친 후보만 저장한다.
- **학습:** 처음부터 CPU 학습. OPEN1000–3와 합성12장 GraphML의 약한 정답640패치,
  절차적으로 생성한1,200개 장면. 강도·획 두께·회전·문자 잡음·점선·근접 평행선·대각선.
  기존 v6 기호 모델 학습셋과 혼동하면 안 된다. 토폴로지 모델은 Pahala/Virden/Ruttan을 학습하지 않았다.
- **재현:** 시드20261029, AdamW, batch8, 16epochs×100steps, CPU4threads,
  자세한 손실/코드 해시는 TRAINING.json. Torch/OpenCV 비교의 최대 오차는 모델 메타데이터 참조.
- **선택:** 별도 절차 장면160개의6채널 mean IoU에서 epoch16 선택. 33.73%.
  절차 장면 port-mask F1 64.1%, plain-cross F1 0%. 이는 실제 도면 port AP가 아니다.
- **현실 데이터 진단:** 학습에 쓰지 않은 기존 프로젝트의 새 페이지3장, 아주 작은
  고정 영역10기호/8연결/14포트/5접점. 단일 주석자. 접점 정답은 T4개·비접속X1개로 실제 점 표시4방 접속은 포함하지 않는다. 독립 프로젝트 검증·전체 도면 평가가 아니다.
  결과와 오검출을 REPORT.ko.md에 기록한다.
- **배포 정책:** 검증에서 새 router 대체/합집합이 기준선을 이기지 못해,
  기존 v6 인접 관계를 유지한다. 새 포트·선·접점 및 기존 관계와 일치하는 경로만 보조 근거로 제공.
- **주요 실패:** 문자/박스 테두리의 가짜 포트, 짧게 분할된 선에서 T 오판정,
  점선 간격과 가시적인 점 없는 교차, 누락된 기호. 4방 GraphML 노드가 가시적인 점을 뜻하지 않는다.
  관찰 근거 없이 흐름을 생성하지 않으며 모델만으로 국제표준 식별자를 선정하지 않는다.
- **범위:** 선·포트·접점을 개별 수정/승인하고 정답으로 수집하는 UI는 후속이다.
  현재 요소 승인은 그 속성 안의 포트까지 확정하지 않는다.
- **데이터:** 사용자 운영 파일을 학습하지 않았다. PID2Graph 유래 가중치·메타데이터는
  CC BY-SA4.0 귀속과 출처를 NOTICE.md에 명시. 원본 엔지니어링 도면은 배포하지 않는다.
