# v8: 실제 점 정답으로 보강한 포트·접점과 하이브리드 추적

기호 검출기는 v6의 고정 YOLOX-Nano 그대로다. 전면6채널 지도(v7) 대신
선과 기호 경계의 후보 주변만 HOG/잉크/팔 방향 특징으로 분류하는 OpenCV
random forest2개를 학습한다. 기존 연결을 보존하고, 점수 기준을 통과한
관찰 경로를 동일한500연결 한도 안에서 추가한다. DXF는 기존 원시 기하
연결을 유지한다. 모든 새 요소·포트·접점·연결은 검토 필요 상태다.

## 데이터 역할

- 실제 수동 학습: 기존 v7 평가3개 영역(Virden9/11, Pahala19)을 **명시적으로
  학습으로 전환**, 기존 개발 영역Virden5/Ruttan50 추가. 실제 포트32개와
  양성/음성 접점19개. 이전 평가3장의 개선은 훈련 진단일 뿐 새 성능 증거가 아니다.
- 실제 추가 검토: OPEN1000–3의 소스 점60개를 원본 잘라보기로 확인했다.
  degree2 모서리는 접점이 아니며 모호한4개 탭 예는 제외했다.
- 약한 학습: OPEN1000–3 + 기존 합성 학습12장의 GraphML 포트 정답.
  약한 정답과 수동 정답을 구분한다. 절차적300장으로 점/T/X와 획·명암 변화를 보강.
- 검증: OPEN1004–5, 합성4장, Pahala20, Virden7, Ruttan62. 수동 포트38개,
  접점5개. Ruttan62의 누락T2개는 별도 원본 감사로 보완한 검증 파일에 기록했다.
  최초 비교의 포트 범위 불일치도 수정했다. `VALIDATION-iteration-1.json`은 최종
  비교에 쓰지 않는 개발 이력이다. 학습·새 테스트 정답은 이 감사에서 변경하지 않았다.
- 새 평가: Virden10/12·Pahala18. 31기호·67연결·39포트·12접점. 원본만 보고
  영역/정답을 정한 뒤 첫 v8 추론 전에 고정했다. 원래 후보Ruttan52는 희미한
  기계 평면도로 신뢰할 P&ID 접점을 주석하기 어려워 **추론 전** Virden12로 바꿨다.
  기존 프로젝트의 새 페이지이므로 독립 프로젝트·전면 GT라고 주장하지 않는다.
- 나머지 v7의22장은 이전에 본 회귀/학습 진단으로 별도 집계한다.

단일 주석자의 시각 전사이며 공학 검증 정답이 아니다. 일부 원형 좌표는
Hough로 보조하고 원본 위에서 다시 확인했다. bbox·포트·선으로 정의한
가시적 인접 관계이며 숨은 제어 의미나 실제 유체 방향을 승인하지 않는다.

## 선택과 해석

9검증장·5출처 그룹의 평균 연결 F1을 최대화하고, 동률이면 포트 F1·접점 F1로
선택했다. 전체 조합·기준선·선택은 `VALIDATION.json`, `MODEL-SELECTION.json`.
고정 추출/가중치/임계값/정답/평가기 해시는 `FROZEN.json`에 있다.

접점 **검출 후보**는 근접 기호·문자 제외, 짧은 선의 꺾임 제외, 실제 팔 확인,
점수 순 좌표 억제를 거친다. 이와 별도로 추적에서 사용하는 낮은 점수의
**접속 가설**도 `routing_contacts`에 저장한다. 검출 정밀도와 접속 가설의
정밀도를 혼동하면 안 된다. 최종 평가에서 두 목록을 따로 제공한다.
포트/접점 점수는 보정된 확률이 아닌 tree vote이며 모두 검토 필요다.

## 재현

기존 자료 준비는 v5/v6 문서, 새 페이지는 `fetch_pages.py`를 따른다.
원본 PDF·PNG·전체 OCR은 Git과 Docker 컨텍스트에서 제외한다.

```bash
# OpenCV/NumPy/Pillow만으로 CPU 학습; PyTorch/GPU 불필요
OMP_NUM_THREADS=1 .venv/bin/python evaluation/v8/train.py
# 학습 산출물을 임시 모델 폴더에서 backend/assets로 복사한 뒤 검증
PATH=/tmp/lineage-ocr-bookworm/bin:$PATH OMP_NUM_THREADS=1 .venv/bin/python evaluation/v8/validate.py
# 제공한 고정 가중치와 코드로 정확한 평가 재실행 권장
PATH=/tmp/lineage-ocr-bookworm/bin:$PATH OMP_NUM_THREADS=1 .venv/bin/python evaluation/v8/evaluate.py --runs 3
```

훈련160trees·depth18, seed20261030. 환경은 requirements.txt, 코드/자료/가중치
해시는 TRAINING.json 참조. OpenCV 버전에 따른 재학습 비트 일치는 보장하지 않는다.
선택값은 포트0.5, 경로 접속0.25, 추가 경로 끝점 점수0.55, 표시 접점0.45.
기준선은 실제 배포했던 앱 커밋43041df다. 고정 기준선 패키지 전체를 분리해 로드한다.

최종 비교는 동일한 OCR 바이너리/언어 데이터, 같은 최대4800px 기호·2400px뷰어,
각 장3회·버전 순서 교대로 실행한다. 추가 경로 수뿐 아니라 TP/FP/FN·F1과
기호 양끝이 검출된 정답만의 조건부 재현율도 기록한다. 시간은 OCR·기호·추적이며
업로드·이미지 디코딩·PDF 렌더링·저장을 제외한다. 운영 전체 시간은 별도 기록한다.
